L. Scientific Boundary and Mandatory Caveats

Attention weights describe temporal token-to-token allocation inside the Transformer Encoder. They are NOT raw-feature importance, NOT causal attribution, NOT proof of model reasoning.
Temporal, not Feature
Attention axes represent temporal token positions. Input Linear(33, D) mixes the 33 features before self-attention. A source position is a TEMPORAL position, NOT a raw feature.
Not Causal
High attention weight at a lag does NOT prove that timestamp causes the prediction. It is an internal allocation diagnostic only.
Head Alignment Not Assumed
Head index 0 in one seed is NOT assumed to have the same learned semantic role as head index 0 in another seed. Same numeric index = same architectural position only.
Entropy is Concentration Only
H and H_norm are distribution-concentration diagnostics. They are NOT model confidence, NOT prediction quality, NOT interpretability quality.
Phase 53 PNG != Phase 54 numerical source. Phase 53 heatmaps are visualization context only. Phase 54 numerical source is the frozen Phase 52 raw LAST_QUERY NPZ: last_query_attention_seed{42,123,2026}.npz. No PNG pixel digitization is permitted in Phase 54 code paths.
