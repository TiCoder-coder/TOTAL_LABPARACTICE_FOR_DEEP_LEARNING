📖 About This Repository

This repository is a centralized collection of Deep Learning laboratory exercises and practical projects developed throughout the course.

The main purpose is to document the complete learning process, including:

🧩 Understanding fundamental Deep Learning concepts.

🔢 Working with tensors, datasets, data loaders, and transformations.

🏗️ Designing and implementing neural network architectures.

🔁 Building complete training and evaluation pipelines.

📊 Visualizing loss, accuracy, predictions, and experimental results.

🧪 Comparing models and hyperparameters through controlled experiments.

💾 Saving, loading, and reusing trained models.

🚀 Applying Deep Learning techniques to practical problems.

The repository is continuously updated as new labs, exercises, experiments, and project materials are completed.

📊 Experiment Principles

Each experiment in this repository follows several important principles:

Establish a reproducible baseline before building a more complex model.

Split training, validation, and test data correctly.

Fit preprocessing operations only on the training data.

Change one experimental factor at a time whenever possible.

Record configurations, metrics, observations, and conclusions.

Select models using validation results.

Use the test set only for final evaluation.

Never report results that have not been produced by an actual run.
