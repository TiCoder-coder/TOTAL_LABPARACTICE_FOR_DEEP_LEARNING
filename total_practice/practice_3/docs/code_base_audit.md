## B. Core Roles

- `notebook_practice_3/practice_3.ipynb`: The singular presentation notebook orchestrating the final 16 phases. Driven entirely by saved artifacts without triggering live training.
- `processing_own_phase/`: Contains standalone Python scripts defining the logic for data loading, training loops, evaluation, and visualization.
- `runs/practice_3_v2_3/`: Houses the raw TensorBoard logs, checkpoint weights, and `trainer_state.json` histories generated by the Hugging Face `Trainer`.
- `docs/result/practice_3_v2_3/`: The authoritative evidence layer. Contains JSON metric files, ranking tables, confusion matrices, and the final exported model (`final_saved_model/`).

## C. Data Flow

```text

  → Train (7676), Validation (960), Holdout (960)

  → processing_own_phase/final_holdout_evaluation_v2_3.py (One-Time Evaluation)
  → docs/result/practice_3_v2_3/final_holdout_metrics.json
  → notebook_practice_3/practice_3.ipynb (Visualization)
```

## D. Protocol Enforcement

- **Holdout Isolation**: Holdout is loaded only once at the very end of the pipeline. Its `evaluation_count` is strictly verified to be 1.
- **Official Test Exclusion**: The Hugging Face `test` split is explicitly ignored and unloaded to prevent data leakage.
- **Read-Only Notebook**: `practice_3.ipynb` renders the analysis dynamically from JSON/CSV files rather than triggering live `Trainer` execution, ensuring metric stability and immediate execution.
